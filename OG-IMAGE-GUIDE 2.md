## 📐 TECHNICAL SPECIFICATIONS

### Required Dimensions
- **Size:** 1200 x 630 pixels (exact)
- **Aspect Ratio:** 1.91:1
- **File Format:** JPG or PNG (JPG recommended for smaller file size)
- **File Size:** Under 5MB (ideally under 300KB for fast loading)
- **Color Space:** RGB

### Display Sizes Across Platforms
- **Facebook Feed:** 1200 x 630px
- **Facebook Shared Link:** 1200 x 630px  
- **LinkedIn Feed:** 1200 x 627px (crops to 1200 x 630)
- **Twitter Card:** 1200 x 628px (crops to 1200 x 600)
- **Slack Preview:** 1200 x 630px
- **WhatsApp Preview:** 400 x 400px (center crop from 1200 x 630)

### Safe Zones
- **Primary Text Zone:** Center 1000 x 500px (avoid edges)
- **Mobile Safe Zone:** Center 800 x 420px (critical for text legibility)
- **Logo Placement:** Top-left or bottom-right, 60px from edges

---

## 🎨 DESIGN BEST PRACTICES

### Text Guidelines
1. **Headline:** 40-60 characters maximum
2. **Font Size:** Minimum 60px for headlines (80-100px ideal)
3. **Font Weight:** Bold or Semi-Bold (700-600)
4. **Line Height:** 1.2-1.3 for headlines
5. **Contrast Ratio:** Minimum 4.5:1 (text to background)
6. **Font Family:** Poppins Bold (brand consistency)

### Visual Hierarchy
1. **Primary Message:** Largest, top-third of image
2. **Supporting Text:** Medium size, middle-third
3. **Brand/Logo:** Small, bottom or top corner
4. **Background:** Subtle, doesn't compete with text

### Color Strategy
- **Brand Navy (#0a253c):** Professional, trustworthy
- **Brand Teal (#008080):** Scientific, modern
- **White Text on Navy:** High contrast, readable
- **Accent Gold (#ffb800):** Call attention to key words

### Imagery Guidelines
1. **Mouse/Science Photos:** Use authentic lab imagery
2. **Abstract DNA/Science Graphics:** Modern, not clip-art
3. **Avoid:** Stock photos, generic images, busy backgrounds
4. **Tip:** Gradient overlays help text readability

## 📂 FILE ORGANIZATION

### Folder Structure
```
/public/images/og/
  /core/          (homepage, about, contact, etc.)
  /services/      (knockout, knockin, humanized, etc.)
  /disease/       (disease model pages)
  /technology/    (Cre-Lox, ROSA26, etc.)
  /catalog/       (catalog model pages)
  /resources/     (guides, tools, blog)
  default.jpg     (fallback image)
```

- Format: `{slug}-og.jpg`
- Examples:
  - `homepage-og.jpg`
