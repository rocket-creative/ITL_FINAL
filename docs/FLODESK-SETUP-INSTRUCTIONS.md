# Flodesk Form Setup Instructions

## Current Status

⚠️ **The Flodesk form is currently a placeholder.** You need to add your actual Flodesk embed code to complete the integration.

## Why the Placeholder?

Flodesk forms require **actual embed code** from your Flodesk account, not just a form ID. The URL `link.flodesk.com` doesn't exist - Flodesk uses custom embed scripts.

## How to Get Your Flodesk Embed Code

### Step 1: Login to Flodesk
Go to https://app.flodesk.com and login

### Step 2: Navigate to Your Form
1. Click **Forms** in the left sidebar
2. Select your "Lab Signals" form (or create one)
3. Customize the form design and fields

### Step 3: Get Embed Code
1. Click the **Embed** button (top-right corner of form editor)
2. You'll see **two code snippets**:
   - **Header code** - Script to load in `<head>`
   - **Inline code** - HTML to place where form appears

### Step 4: Copy the Inline Code

The inline code looks something like this:

```html
<div id="fd-form-689e278b40db38a14e1ffe6b">
  <link href="https://assets.flodesk.com/forms.css" rel="stylesheet">
  <form>
    <!-- Form fields generated by Flodesk -->
  </form>
</div>
```

## Implementation Options

### Option A: Replace FlodeskForm.tsx (Recommended)

**File:** `src/components/UXUIDC/FlodeskForm.tsx`

Replace the placeholder `<div>` content with your Flodesk inline embed code:

```tsx
export default function FlodeskForm({ formId }: FlodeskFormProps) {
  return (
    <div 
      style={{
        width: '100%',
        maxWidth: '550px',
        margin: '0 auto',
      }}
      dangerouslySetInnerHTML={{
        __html: `
          <!-- PASTE YOUR FLODESK INLINE CODE HERE -->
          <div id="fd-form-689e278b40db38a14e1ffe6b">
            <!-- Flodesk form HTML -->
          </div>
        `
      }}
    />
  );
}
```

### Option B: Add Header Script

**File:** `src/app/layout.tsx`

Add Flodesk's header script to your root layout:

```tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <head>
        {/* Other head content */}
        
        {/* Flodesk Header Script */}
        <Script id="flodesk-header" strategy="beforeInteractive">
          {`
            // PASTE YOUR FLODESK HEADER CODE HERE
          `}
        </Script>
      </head>
      <body>{children}</body>
    </html>
  );
}
```

### Option C: Use Script Component (Most Flexible)

**File:** `src/components/UXUIDC/FlodeskForm.tsx`

```tsx
'use client';

import Script from 'next/script';
import { useState } from 'react';

export default function FlodeskForm() {
  const [scriptLoaded, setScriptLoaded] = useState(false);

  return (
    <>
      <Script
        src="https://assets.flodesk.com/universal.js"
        strategy="lazyOnload"
        onLoad={() => setScriptLoaded(true)}
      />
      
      <div 
        id="fd-form-689e278b40db38a14e1ffe6b"
        dangerouslySetInnerHTML={{
          __html: `
            <!-- YOUR FLODESK INLINE CODE HERE -->
          `
        }}
      />
    </>
  );
}
```

## Testing Without Flodesk (Development)

For now, you can test the gated content flow using the placeholder form. To simulate a successful submission for testing:

### Temporary Test Solution

**File:** `src/components/UXUIDC/FlodeskForm.tsx`

Add a test button that triggers the unlock:

```tsx
'use client';

export default function FlodeskForm() {
  const handleTestSubmit = () => {
    // Simulate Flodesk postMessage event
    window.postMessage({
      type: 'fd-form-submit',
      formId: '689e278b40db38a14e1ffe6b'
    }, '*');
  };

  return (
    <div>
      {/* Placeholder form UI */}
      <button onClick={handleTestSubmit}>
        TEST: Unlock Content (Dev Only)
      </button>
    </div>
  );
}
```

This will trigger the NewsletterGate's postMessage listener and unlock the content for testing purposes.

## Alternative: Use Direct Form Link

If you want users to fill out the form on Flodesk's site instead of embedded:

### Step 1: Get Your Form Link
1. In Flodesk, go to your form
2. Click **Share** → **Get Link**
3. Copy the form URL (e.g., `yourname.myflodesk.com/lab-signals`)

### Step 2: Update FlodeskForm Component

```tsx
export default function FlodeskForm() {
  return (
    <div style={{ textAlign: 'center', padding: '30px 20px' }}>
      <p style={{ marginBottom: '20px', fontSize: '.95rem' }}>
        Subscribe to access this article and receive biweekly updates
      </p>
      <a
        href="https://yourname.myflodesk.com/lab-signals"
        target="_blank"
        rel="noopener noreferrer"
        style={{
          display: 'inline-block',
          padding: '12px 24px',
          backgroundColor: '#fb0',
          color: '#000',
          textDecoration: 'none',
          borderRadius: '6px',
          fontWeight: 700,
        }}
      >
        Subscribe on Flodesk →
      </a>
    </div>
  );
}
```

**Note:** With this approach, users leave your site to subscribe, then manually return. You'd need to implement the "Sign in with email" flow for returning visitors.

## Recommended Approach

**For Production:** Use Option A or C above with actual Flodesk embed code.

**For Development/Testing:** Use the temporary test solution to verify the gated content flow works correctly before adding real Flodesk integration.

## Verification Checklist

After adding real Flodesk code:

- [ ] Form loads without errors
- [ ] Form fields are styled correctly
- [ ] Form submits to Flodesk successfully
- [ ] New subscriber appears in Flodesk dashboard
- [ ] Content unlocks after submission
- [ ] Cookie is set (`itl_labsignals_access`)
- [ ] Subscriber receives welcome email (if configured)
- [ ] No CSP errors in browser console

## Security Note

When you add the real Flodesk code, ensure:
- ✅ Flodesk domains are whitelisted in CSP (already done)
- ✅ Form submissions go directly to Flodesk
- ✅ No sensitive data is stored client-side
- ✅ Email addresses are handled securely by Flodesk
